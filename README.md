# Arabic Phoneme Classifier

A small PyTorch learning project for classifying spoken Arabic phonemes from audio using Mel spectrograms and a convolutional neural network (CNN).

## Current scope

The project currently focuses on six Arabic phonemes with fatḥah:

`قَ` `كَ` `تَ` `طَ` `سَ` `صَ`

The project is a work in progress and will be expanded to cover more Arabic phonemes and multi-speaker datasets.

## Setup

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Note

Local recordings, downloaded datasets, trained model checkpoints, and generated audio are intentionally excluded from the repository.
